# max目标相机 使用说明

**版本：1.4.1 · 2026-11-24**

Maya 独立机位／目标相机。入口：**创建 → 摄影机 → max目标相机**。

## 1. 安装与刷新

1. **先解压整个安装包**，保留文件夹结构，不要从 ZIP 内直接拖文件。
2. 打开 Maya，将 `install_max_target_camera.py` **文件本身**从资源管理器拖进三维视口。
3. 确认安装，看到“安装完成”后使用上述菜单。
4. 点击菜单名称进入**鼠标拖动创建**；点击右侧**小方框**打开参数面板。

安装器只写入自己的 Maya 用户模块目录，不修改 Maya 安装文件、用户原有 `userSetup.py`、`Maya.env` 或当前场景。升级安装会备份本工具的旧安装文件，不会把备份放进这个安装包。

**已打开的 Maya 没刷新：**把 `reload_max_camera_menu.py` 文件拖进视口。此入口依赖同文件夹中的 `load_menu_now.py`，不要单独删除或移走它。

如果 Maya 弹出脚本安全提示，请自行确认；本工具不会关闭或绕过安全设置。

## 2. 创建：按下目标 → 拖出相机 → 松开完成

1. 点击 **创建 → 摄影机 → max目标相机**。
2. 在三维视口里按住鼠标左键，**按下位置固定为目标点**。
3. 拖出一段距离确定**相机机位**，拖动期间目标点不动；松开鼠标完成，并选中相机，随后可用 **W** 移动。
4. 不想创建时按 **Q** 退出。单击而不拖动不会生成零距离相机。

v1.4.1 修正了鼠标创建的顺序；不会交换或修改已存在相机的机位与目标。

机位与目标放在观察视口的焦点平面附近，而不是贴到观察相机身后；透视和正交视口均可用。默认图标按两点距离缩小显示。

参数面板另有两个入口：
- **视野内创建（近距离）**：一键把机位与目标都放在当前视野附近。
- **复制视口机位**：明确需要复制观察视角时使用；只复制当前帧的机位、视线和镜头参数，不复制源动画。此模式有意把新相机放在观察机位，和近距离创建不同。

## 3. 移动不附加翻滚，滚转由用户控制

| 操作 | 使用方式 |
|---|---|
| 移动机位 | 选相机，按 **W**；目标保持原位，默认保持世界上方向水平 |
| 移动目标 | 选绿色小方框，按 **W**；机位不随目标平移 |
| 主动滚转 | 选相机，按 **E**，使用**本地 Z 轴**；也可编辑 Rotate Z／Roll 或面板“滚转” |
| 滚转动画 | 给 Rotate Z／Roll 打关键帧；之后移动机位不会清零或覆盖这些关键帧 |
| 焦距 | 编辑 Maya 原生 Focal Length，或 Lens／面板“焦距” |
| 目标距离 | 编辑面板“目标距离”；目标沿视线移动，机位不动 |
| 显示大小 | 调整“目标框缩放”“相机图标缩放”，不改变两点位置 |
| 原地转头／俯仰 | 移动目标，或展开面板的摇摄操作 |
| 绕目标环绕 | 选整体后按 **E**，或用面板的环绕操作 |
| 打关键帧 | 点击“给控制器打关键帧”，或单独给需要的控制参数打关键帧 |

**默认 Roll 为 0。** 即使创建时观察视口有倾斜，也不把这种倾斜自动带入新相机。移动只改变位置与朝向目标的俯仰／方位，不额外添加滚转；用户主动设置的滚转或滚转动画仍然生效。

通道盒 **Target Distance (readout)** 和原生 Center of Interest 是实测距离，保持只读；修改距离请用面板输入框。修改通道盒或时间线之后，可点 **“刷新列表 / 参数”** 读取当前值；关闭面板不影响相机跟随。

## 4. 修复已有相机的移动翻滚

1. 建议先自行保存场景备份。
2. 打开参数面板，选择对应相机，或点击“识别所选相机 / 目标”。
3. 点击 **“修复移动翻滚 / 回正（保留滚转关键帧）”**。

此操作启用世界上方向锁定，保持机位、目标位置不变；只把没有关键帧、没有外部驱动且未锁定的滚转值回零。已有滚转关键帧和外部驱动会保留，因此带有用户滚转动画的相机不一定在每一帧都显示水平。支持撤销。**仅加载新版代码不会自动修复场景里的全部旧相机。**

早期版本如需升级控制器接线，先使用 **“升级当前旧版相机（保留动画 / 可撤销）”**。标准旧版的 Roll、Lens 动画曲线会保留，不是烘焙重建。引用对象或不安全的自定义接线可能被拒绝处理，避免覆盖用户改动。

## 5. 极点、手动 UP 与兼容性

- 这不是自由相机：X/Y 朝向由目标计算。移动目标可转头，整体控制器可用于环绕。
- 镜头正对／背对世界上方向时，水平基准存在极点，附近仍可能翻转；需要这种镜头运动时，用 **“手动 UP（取消水平锁）”** 显示并调整 UP，必要时给它打关键帧。手动 UP 会退出默认的世界水平锁定；要恢复，使用“修复移动翻滚 / 回正”。
- 不声称 Maya 全部鼠标导航、快捷键、世界坐标旋转与 3ds Max 完全一致。
- 兼容目标：Maya **2018–2026**；实际运行验证：**Maya 2023**。Python 2.7 语法检查通过不代表其他 Maya 版本已实测。
- v1.4.0 已通过 24 项既有 GUI 回归、10 项水平与创建专项检查、5 项安装器检查，以及真实鼠标拖动创建／原生 W 手柄移动验收。该版收尾追加 8 项面板／菜单回归，无错误或警告。v1.4.1 补充 10 项回调单元检查、5 项安装器检查及 Maya 2023 真实鼠标拖动验收：按下位置为目标、拖动位置为相机、松开选中相机，Roll 为 0；既有机位与关键帧不变。精简包不附测试代码、历史报告或旧版本。
- 保存后的相机使用 Maya 原生节点，不依赖外部插件、表达式、scriptNode 或持续运行的脚本回调。
