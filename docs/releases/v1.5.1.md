# Maya Max 目标摄像机 v1.5.1

## 1. 稳定维护：保留当前可用功能
- 保留 v1.5.0 的 **按下定目标 → 拖出相机 → 松开完成**、独立机位/目标、世界水平锁定和主动 Roll。
- 保留 **相机图标 × / 目标框 ×** 独立显示滑块、倍率输入、×2、×0.5、恢复默认。
- 保留跟随 Maya 当前默认切线打帧；已有手工切线、全局偏好和场景不会在升级时被自动改写。
- 除版本常量外，不改变 v1.5.0 运行脚本逻辑。本版主要收束支持范围、完善说明和增加发布校验。

## 2. 不包含摄像机 R 缩放实验
- 摄像机 **R 手柄显示缩放**的未发布原型在验证中出现闪退后已停止，不纳入本版；它也没有进入 v1.5.0 正式包。
- 相机真实 Scale 继续锁定，不接管 Maya 的 R，不改变普通物体缩放。
- 创建后需要放大相机图标，请选中相机，在面板 **仅显示大小 → 相机图标 ×** 调整；无需重新创建。
- 目标点保留现有行为；只调整显示时推荐“目标框 ×”，不要把原生 R 的目标变换 Scale 当作独立显示通道。

**这是稳定维护更新，不是新增 R 功能，也不声称修复了旧正式版中不存在的实验功能。**

## 安装 / 升级
1. 下载下方 `maya_max_target_camera_v1.5.1.zip`，完整解压。
2. 把 `install_max_target_camera.py` 文件拖进 Maya 视口并确认。
3. 使用 **创建 → 摄影机 → max目标相机**。旧会话菜单未刷新时，可拖入 `reload_max_camera_menu.py`；保留同目录的 `load_menu_now.py`。
4. 加载不会自动调整旧相机的显示、位置或动画。安装器仅备份/替换自己的模块文件，不改用户启动脚本、`Maya.env` 或场景。

已使用 v1.5.0 的用户无需为相同功能中断当前工作；需要新版标识与说明时再升级即可。

安装包仍只有 **6 个脚本 + 使用说明 + MIT LICENSE，共 8 文件**，附 `SHA256SUMS.txt`。保留 v1.5.0 / v1.4.1 历史下载。本版沿用中英文教程、相关搜索标签和既有无水印配图；原面板截图标明沿用 v1.5.0，不冒充新实测。

## 验证
- **37 项普通 Python 检查通过**：11 项拖动回调、13 项显示/缓动策略、5 项安装器、8 项公开包检查。
- 新增版本一致性、相机 Scale 锁定、无实验 R 模块以及 ZIP 可重复构建检查。
- 本轮没有启动 Maya 做新 GUI 验证。此前 v1.5.0 的 **18 项显示/缓动专项 + 24 项既有 GUI 回归**属于历史验证，不算作本版新增实测。
- 只在 **Maya 2023** 有历史运行验证；Maya 2018–2026 仍是兼容目标，不代表全部年份实测。

## English summary
v1.5.1 is a stable maintenance release retaining v1.5.0 runtime behavior, except for the version labels. It updates bilingual guidance, download links and release safeguards without adding experimental camera scaling.

The unpublished native-R camera display-scaling prototype was discontinued after validation crashes and was never included in a public release. Camera transform Scale stays locked. Use the display panel to resize the camera icon after creation; existing target operations and Maya-default key tangents are retained.

37 plain-Python checks pass, including four new release guards. There is **no new Maya GUI test claim** for this maintenance release; the 42 GUI checks documented for v1.5.0 are historical evidence. The eight-file ZIP, SHA256 manifest, MIT license and previous releases remain available. Independent community tool, not endorsed by Autodesk and not a `.max` scene importer.
